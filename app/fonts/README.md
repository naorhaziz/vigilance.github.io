# Vigilance Font Placeholder

This directory is reserved for the GeistMonoVF.woff font file.

For development purposes, you can:
1. Download Geist Mono from: https://vercel.com/font
2. Place the `GeistMonoVF.woff` file in this directory
3. Or update `app/layout.tsx` to use a system monospace font as fallback

The application will work with the fallback monospace font if the Geist Mono file is not present.
